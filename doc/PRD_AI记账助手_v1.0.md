# AI 智能记账助手 — 需求文档（PRD）

**版本**：v1.0  
**日期**：2026-08-14  
**平台**：Android （Flutter 跨平台）  
**数据存储**：纯本地，零服务端

---

## 1. 项目概述

一款面向个人用户的离线智能记账应用。用户可通过口语化自然语言快速记录消费（如"买了个面包花了五块，买了包烟花了十元"），由 AI 自动解析为结构化账单数据。所有数据仅存储于手机本地，支持日常账单管理、多维度检索、每周一自动生成消费周报（含 AI 总结与数据可视化）。

---

## 2. 目标用户与使用场景

| 场景 | 描述 |
|------|------|
| 快速记账 | 用户消费后，用自然语言一句话记录多笔支出，无需手动选择分类和填写表单 |
| 补录历史 | 用户发现昨天漏记一笔，可选择昨天日期进行补录 |
| 消费回顾 | 用户通过搜索和筛选查找历史账单，支持修改和删除 |
| 周期复盘 | 每周一打开 App，自动收到上周消费周报，查看支出构成与 AI 建议 |

## 3. 功能需求

### 3.1 记账输入模块

| 编号 | 需求 | 优先级 | 详细说明 |
|------|------|--------|----------|
| F1-1 | 自然语言输入 | P0 | 支持口语化、多条混合输入，不强制分隔符，由 AI 自动识别边界。如："买了个西瓜花了五十 买了个苹果花了五块" |
| F1-2 | 日期选择 | P0 | 记账页提供日期选择器（默认当天），用户可切换为过去日期进行补录。AI 不负责推断日期，仅使用用户选定的日期 |
| F1-3 | 解析触发 | P0 | 用户输入完成后点击「解析」按钮，调用 AI 服务进行结构化解析 |
| F1-4 | 解析确认页 | P0 | AI 解析结果不直接入库，先展示确认页，允许用户逐条修改描述、金额、类别，确认后保存 |
| F1-5 | 解析失败处理 | P0 | 若 AI 返回格式错误、缺少金额、缺少消费内容等，弹出弹框提示具体失败原因，不保存任何数据 |

### 3.2 AI 智能解析模块

| 编号 | 需求 | 优先级 | 详细说明 |
|------|------|--------|----------|
| F2-1 | 多平台支持 | P0 | 支持 DeepSeek、阿里云百炼、商汤日日新，以及用户自定义 OpenAI 兼容接口 |
| F2-2 | 模型配置 | P0 | 设置页配置默认 AI Provider、API Key、模型名称。自定义模式下需填写 API Base URL 和模型名 |
| F2-3 | 预设类别映射 | P0 | AI 必须将消费映射到以下 8 个预设类别之一：餐饮、交通、购物、娱乐、居住、医疗、教育、其他 |
| F2-4 | 字段提取 | P0 | 每条记录必须提取：description（消费内容）、amount（金额数字）、category（类别） |
| F2-5 | 批量解析 | P0 | 单次输入可能包含多条记录，AI 需返回 JSON 数组格式 |

### 3.3 账单管理模块

| 编号 | 需求 | 优先级 | 详细说明 |
|------|------|--------|----------|
| F3-1 | 首页今日视图 | P0 | 首页默认展示当日所有账单，按创建时间倒序，顶部显示今日总支出。无记录时展示空状态 |
| F3-2 | 账单编辑 | P0 | 支持修改已保存账单的描述、金额、类别、日期 |
| F3-3 | 账单删除 | P0 | 支持删除单条账单，删除前需二次确认 |
| F3-4 | 关键词搜索 | P0 | 支持按消费描述关键词实时搜索（防抖 500ms） |
| F3-5 | 多维度筛选 | P1 | 支持按类别（多选）、日期范围、金额区间组合筛选 |
| F3-6 | 搜索入口 | P0 | 首页右上角提供搜索图标，跳转至搜索页 |

### 3.4 周报模块

| 编号 | 需求 | 优先级 | 详细说明 |
|------|------|--------|----------|
| F4-1 | 自动生成 | P0 | 每周一用户打开 App 时，若检测到上周（上周一至周日）有账单且尚未生成周报，则自动调用 AI 生成 |
| F4-2 | 周报内容 | P0 | 包含两部分：(1) AI 生成的文字总结（≤150 字）；(2) 上周各分类支出占比饼图与总支出金额 |
| F4-3 | 弹窗展示 | P0 | 周报生成后以弹窗/全屏页形式展示，用户可关闭 |
| F4-4 | 历史回看 | P0 | 支持查看所有历史周报列表，按时间倒序，点击进入详情 |
| F4-5 | 本地存储 | P0 | 周报生成后持久化存储本地，回看时直接读取，不重复调用 AI |

### 3.5 设置模块

| 编号 | 需求 | 优先级 | 详细说明 |
|------|------|--------|----------|
| F5-1 | AI 配置 | P0 | 设置页提供：Provider 选择器、API Key 输入（密文）、模型名称输入、自定义 API 地址输入（自定义模式下显示） |
| F5-2 | 配置持久化 | P0 | AI 配置加密存储于本地（SecureStorage），App 启动时自动读取 |
| F5-3 | 关于信息 | P2 | 展示 App 名称与版本号 |

## 4. 非功能性需求

| 类别 | 需求 | 说明 |
|------|------|------|
| **性能** | 冷启动 ≤ 2 秒 | 含数据库初始化 |
| **性能** | 解析响应 ≤ 5 秒 | 含网络请求与 JSON 解析 |
| **离线** | 完全离线可用 | 除 AI 解析和周报生成需网络外，查账、编辑、删除均无需网络 |
| **安全** | API Key 加密 | 使用 Flutter Secure Storage，不存储于 SharedPreferences |
| **安全** | 数据隐私 | 所有消费数据仅存本地 SQLite/Isar，不上传任何第三方服务器 |
| **兼容性** | 系统版本 | Android 8.0+ |
| **UI** | 视觉风格 | 以 iOS Cupertino 设计为基底，允许现代设计元素（大圆角、柔和阴影、毛玻璃） |

## 5. 界面与交互需求

| 页面 | 核心交互 |
|------|----------|
| 首页 | 顶部今日总支出 → 中部账单列表 → 底部悬浮「记一笔」按钮 → 右上角搜索 |
| 记账页 | 日期选择行 → 大文本输入框 → 解析按钮 → 失败弹框 / 成功跳转确认页 |
| 确认页 | 可编辑列表（描述/金额/类别）→ 底部保存按钮 |
| 搜索页 | 顶部搜索栏 → 筛选标签栏（类别/日期/金额）→ 结果列表 |
| 详情/编辑页 | 字段表单 → 编辑/完成切换 → 底部删除按钮（二次确认） |
| 周报页 | 时间段标题 → AI 总结卡片 → 饼图 → 总支出 → 历史入口 |
| 设置页 | 分组列表：AI 配置（Provider/API Key/模型）→ 关于 |

---

## 6. 数据需求

| 数据实体 | 核心字段 |
|----------|----------|
| 账单（Transaction） | id, description, amount, category, date（日期）, createdAt |
| 周报（WeeklyReport） | id, weekStartDate, weekEndDate, totalExpense, categoryBreakdown, aiSummary, generatedAt |
| AI 配置（AIConfig） | provider, apiKey, apiUrl, modelName |
